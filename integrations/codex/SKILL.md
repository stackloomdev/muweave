# Muweave operator

Read `README.md` in this directory for the complete import, revision and export protocol. Follow the host's installed browser tool documentation; do not assume a fixed plugin path.

Open the Muweave static site and discover its native WebMCP tools. Read capabilities and the current project before editing. Use the existing project unless the user asks for a new one. Human edits and agent commands operate on the same state.

Plan visible scene content, narration, captions and production notes separately. Perform research, fact-checking, image generation and speech synthesis using host tools when available and authorized. Import generated files through an browser file chooser; do not put local filesystem paths in canvas nodes.

Submit small meaningful command batches with current revisions and unique request IDs. Read back changes, inspect the real canvas, validate text overflow and missing assets, and preserve unrelated edits. Retry uncertain submissions with identical arguments; resolve conflicts from fresh state.

Use measured audio durations. Keep scene gaps at zero unless the user intends a pause. Analyze leading/trailing silence before applying trims; preserve intentional sentence pauses. Import real aligned captions when available. Never narrate notes, labels such as “讲解备注”, or image-generation prompts.

For an independent cover, create and edit a variant and check its layout at the requested ratio. For export, use a version snapshot and inspect the successful job report and file. Report missing generation capabilities and unverified output honestly. Do not substitute a screenshot for an editable project, or a server API check for a native browser-tool check.
