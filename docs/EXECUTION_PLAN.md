# Muweave · 幕织 — 执行计划

2026-09-23：用户明确选择完整浏览器应用，原生 WebMCP 保留 Agent 操作入口。此前 Fastify / 本机 Chromium / 原生 FFmpeg 的试用架构退役，OpenMontage 继续仅作工作流参考。

## 当前实施范围

- 浏览器 IndexedDB：工程、素材 Blob、最近 40 次撤销历史、持久请求回执、冻结导出快照及成品。
- UI 与 WebMCP 共享校验后的事务操作；整数微秒时间轴、版本冲突拒绝、请求去重规则保留。
- Canvas 处理静态图片和封面；Web Audio 解码、实测音频时长、波形和首尾静音；配音导入规范化为 48 kHz PCM WAV。
- MP4 用单线程 ffmpeg.wasm；PNG、ZIP 工程包、SRT 直接由浏览器生成。导出绑定固定版本，支持进度、取消、完成后预览和下载。
- 原生 WebMCP 的文件导入走浏览器文件选择器，随后提交暂存素材；不提供本地 HTTP 上传地址。
- 发布产物只有 `apps/studio/dist` 静态文件；无需业务服务、数据库服务器、Chromium 进程或原生 FFmpeg。Vercel 配置随代码提供，本次不执行上线。
- 旧磁盘工程先通过一次性迁移脚本导出 ZIP，浏览器选择文件导入；不修改旧文件。

## 验收

存储事务回滚 / 多连接并发 / 回执重试 / 撤销恢复；真实浏览器导入图片和音频、静音建议、封面与字幕下载；1080p MP4 尺寸和全片解码、页间音频连续性；导出期间编辑、跨标签取消、刷新后的成品保留与任务中断；工程包往返；禁止 `/api` 和外网请求仍可完成流程；生产静态预览和内置浏览器原生 WebMCP 操作。

实测结果写入 `VALIDATION.md`。长视频与移动端性能、离页续跑、账号和云协作不在当前范围。AI 生图和配音生成仍由用户已选择的宿主工具完成，生成文件通过浏览器导入。
